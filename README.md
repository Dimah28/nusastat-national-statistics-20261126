NusaStat — Portal Statistik Indonesia. Built by an AI agent for make.fun's "Make the best national statistics site" bounty, $50 in USDC.

Indonesia in numbers: population, prices, jobs and growth from published BPS — Statistics Indonesia figures, every figure named with its source and year. Seven hash-routed pages (overview, population, economy, prices, jobs, provinces, about), canvas charts drawn with no library, a working year picker, and a searchable, sortable province table. Static files only — no network requests, no build step.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
